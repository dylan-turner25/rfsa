Calculating Price Loss Coverage (PLC) Payments

library(rfsa)

Introduction

The rfsa package provides tools for calculating Price Loss Coverage (PLC) payments administered by the USDA Farm Service Agency. PLC is a commodity program that provides payments to farmers when the effective reference price exceeds the higher of the national marketing loan rate or the Marketing Year Average (MYA) price.

This vignette demonstrates how to use the calc_plc_payment() function to calculate PLC payments for various crops and scenarios.

Basic PLC Payment Calculations

Understanding the Payment Formula

The PLC payment is calculated using this formula:

Payment = (Reference Price - Comparison Price) × PLC Yield × Base Acres × Coverage Level

Where: - Reference Price = Effective Reference Price (ERP) for recent years, or Statutory Reference Price (SRP) for 2014-2019 - Comparison Price = Higher of MYA Price or National Marketing Loan Rate (NMLR)

Simple Example with Fixed Values

Let’s start with a basic calculation using known values:

# Calculate PLC payment with specified parameters
payment <- calc_plc_payment(
  crop = "corn",
  program_year = 2024,
  base_acres = 100,
  mya_price = 3.50,
  erp = 4.30,
  nmlr = 2.50,
  plc_yield = 180,
  quiet = TRUE
)
#> Error in calc_plc_payment(crop = "corn", program_year = 2024, base_acres = 100, : could not find function "calc_plc_payment"

print(paste("PLC payment for 100 acres of corn:", round(payment, 2)))

Breaking Down the Calculation

# Example showing the calculation components
crop <- "corn"
erp <- 4.30
mya_price <- 3.50
nmlr <- 2.50
plc_yield <- 180
base_acres <- 100
coverage_level <- 0.85

# Step 1: Determine if payment is due
payment_due <- erp > mya_price
print(paste("Payment due (ERP > MYA)?", payment_due))
#> [1] "Payment due (ERP > MYA)? TRUE"

# Step 2: Determine comparison price
comparison_price <- max(mya_price, nmlr)
print(paste("Comparison price (max of MYA and NMLR):", comparison_price))
#> [1] "Comparison price (max of MYA and NMLR): 3.5"

# Step 3: Calculate payment rate per bushel
payment_rate <- erp - comparison_price
print(paste("Payment rate per bushel:", payment_rate))
#> [1] "Payment rate per bushel: 0.8"

# Step 4: Calculate total payment
total_payment <- payment_rate * plc_yield * base_acres * coverage_level
print(paste("Total PLC payment:", round(total_payment, 2)))
#> [1] "Total PLC payment: 12240"

# Verify with function
function_result <- calc_plc_payment(
  crop = crop,
  program_year = 2024,
  base_acres = base_acres,
  mya_price = mya_price,
  erp = erp,
  nmlr = nmlr,
  plc_yield = plc_yield,
  cov_lvl = coverage_level,
  quiet = TRUE
)
#> Error in calc_plc_payment(crop = crop, program_year = 2024, base_acres = base_acres, : could not find function "calc_plc_payment"

print(paste("Function result matches:", round(function_result, 2) == round(total_payment, 2)))

Batch Processing Example

# Example of calculating payments for multiple scenarios
scenarios <- data.frame(
  scenario = c("High ERP", "Low MYA", "No Payment", "Large Farm"),
  crop = c("corn", "corn", "corn", "soybeans"),
  base_acres = c(100, 100, 100, 500),
  mya_price = c(3.50, 2.00, 4.50, 11.50),
  erp = c(4.30, 4.30, 4.00, 12.95),
  nmlr = c(2.50, 2.50, 2.50, 6.20),
  plc_yield = c(180, 180, 180, 50),
  stringsAsFactors = FALSE
)

# Calculate payments
scenarios$payment <- 0
for (i in 1:nrow(scenarios)) {
  scenarios$payment[i] <- calc_plc_payment(
    crop = scenarios$crop[i],
    program_year = 2024,
    base_acres = scenarios$base_acres[i],
    mya_price = scenarios$mya_price[i],
    erp = scenarios$erp[i],
    nmlr = scenarios$nmlr[i],
    plc_yield = scenarios$plc_yield[i],
    quiet = TRUE
  )
}
#> Error in calc_plc_payment(crop = scenarios$crop[i], program_year = 2024, : could not find function "calc_plc_payment"

print("Batch Processing Results:")
#> [1] "Batch Processing Results:"
print(scenarios[, c("scenario", "crop", "base_acres", "payment")])
#>     scenario     crop base_acres payment
#> 1   High ERP     corn        100       0
#> 2    Low MYA     corn        100       0
#> 3 No Payment     corn        100       0
#> 4 Large Farm soybeans        500       0

total_payments <- sum(scenarios$payment)

Summary

The calc_plc_payment() function provides a comprehensive tool for calculating PLC payments with these key features:

Key Parameters

  • crop: The crop name (e.g., “corn”, “soybeans”, “rice”)
  • crop_type: Specific variety for crops with multiple types
  • program_year: The program year for calculation
  • base_acres: Number of enrolled acres
  • mya_price, erp, srp, nmlr: Price parameters (optional, uses FSA data if not provided)
  • plc_yield: Yield parameter (optional, calculated from location if not provided)
  • state, county, fips: Location parameters for yield calculation
  • cov_lvl: Coverage level (default 0.85)
  • quiet: Suppress messages for batch processing

Calculation Logic

  1. If ERP ≤ MYA Price: Payment = 0
  2. If MYA Price ≤ NMLR: Payment = (ERP - NMLR) × PLC Yield × Base Acres × Coverage Level
  3. Otherwise: Payment = (ERP - MYA Price) × PLC Yield × Base Acres × Coverage Level

Best Practices

  • Use quiet = TRUE for batch processing to suppress informational messages
  • Specify crop_type when working with crops that have multiple varieties
  • Provide custom price data when needed for specialized analyses
  • Use location parameters (state, county, fips) for location-specific yields

For more detailed information, see the function documentation with ?calc_plc_payment.
