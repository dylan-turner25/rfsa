📖 Calculating Price Loss Coverage (PLC) Payments

A comprehensive guide to using the calc_plc_payment() function for calculating Price Loss Coverage payments administered by the USDA Farm Service Agency.

This guide covers:

  • Basic PLC payment calculations and formulas
  • Working with different crop types and locations
  • Batch processing for multiple scenarios
  • Custom price data and historical calculations
  • Understanding payment scenarios and edge cases
  • Best practices for production use
View Vignette GitHub Repository

📦 Installation

Install the rfsa package directly from GitHub:

remotes::install_github("dylan-turner25/rfsa", force = TRUE)

🚀 Quick Start

Calculate a PLC payment with just a few lines of code:

library(rfsa)

# Calculate PLC payment for 100 acres of corn
payment <- calc_plc_payment(
  crop = "corn",
  program_year = 2024,
  base_acres = 100,
  quiet = TRUE
)

print(paste("PLC payment:", round(payment, 2)))
