


Update Instructions:

To update the fsaCropAcreage.rds file, open fsa_acreage_urls.xlsx and add a row
corresponding to any new file releases on FSA's crop acreage data webpage: https://www.fsa.usda.gov/news-room/efoia/electronic-reading-room/frequently-requested-information/crop-acreage-data/index

After adding the new row, save and close fsa_acreage_urls.xlsx

Running the R script fsaCropAcreage.R will then update fsaCropAcreage.rds in accordance with any new file releases in fsa_acreage_urls.xlsx
